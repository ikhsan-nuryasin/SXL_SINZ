KONFIGURASI MANUAL

Gunakan runtime yang sudah terpasang

Masukkan path lengkap dari PHP, Apache, Node.js, dan tool lain yang sudah ada. SINZ akan memvalidasi file/folder sebelum menyimpan. Ini bisa dipakai untuk runtime dari Laragon, XAMPP, Homebrew, atau instalasi mandiri.

Path manual belum dimuat.

Bagaimana menemukan path runtime?

Windows · Laragon / XAMPP / instalasi sendiri

Di PowerShell, jalankan where.exe php, where.exe node, atau where.exe httpd untuk melihat executable yang sudah masuk PATH. Jika tidak ditemukan, periksa folder instalasi, misalnya C:\laragon\bin\php\, C:\xampp\apache\bin\, atau C:\Program Files\nodejs\. Untuk Apache, pilih file httpd.exe, bukan folder bin.

macOS · Homebrew

Jalankan which php, which node, brew --prefix httpd, atau brew --prefix mariadb. Masukkan path binary yang dikembalikan untuk file runtime, atau folder bin untuk MariaDB.

Penting

Masukkan path lengkap tanpa tanda kutip. Untuk PHP, pilih php.exe dan php-cgi.exe dari versi yang sama. Untuk MariaDB, folder harus memiliki server, installer, client, admin, dan dump. Menyimpan path tidak menjalankan atau mengunduh runtime; SINZ menggunakannya saat layanan terkait dijalankan.

Catatan: SINZ tidak otomatis mengadopsi database lama dari Laragon/XAMPP. Untuk mencegah data lama berubah, binary MariaDB manual disalin ke runtime privat pada Windows. Pada macOS, binary yang dipilih digunakan dengan data directory privat. Database lama tidak otomatis dipindahkan. MySQL Server murni tidak selalu kompatibel dengan installer MariaDB.

PUBLIKASI KODE

Terbitkan proyek ke GitHub

Ikuti langkah di bawah. File proyek tidak dikirim sebelum konfirmasi.

  1. Isi nama repository dan visibilitas.
  2. Buat pratinjau, lalu periksa file yang dikirim dan dikecualikan.
  3. Konfirmasi daftar file dan aturan .gitignore.
  4. Terbitkan; proses membuat commit lalu mengirimnya ke GitHub.
Isi nama-repository, atau pemilik/nama-repository untuk akun/organisasi tertentu. Private disarankan. Repository Public dapat disalin dan diunduh siapa saja.
Yang perlu disiapkan
  • Git dan GitHub CLI (gh) sudah terpasang.
  • GitHub CLI sudah login: gh auth login.
  • Identitas commit Git sudah diatur: git config --global user.name dan git config --global user.email.

Langkah 2: buat pratinjau untuk memeriksa file sebelum perubahan dilakukan.

      BANTUAN / DOKUMENTASI

      Panduan SINZ

      Panduan singkat untuk memahami alur kerja dan menggunakan SINZ dengan aman.

      Cara kerja

      1. Jalankan aplikasi. Buka SINZ dari Desktop/Start Menu atau folder Applications. Jika menjalankan mode ZIP Windows, gunakan Start-SXL-Website-Sharing.bat. Cloudflare Tunnel disiapkan otomatis ketika diperlukan.
      2. Pilih folder website. Folder harus berisi index.html dan file statis yang dibutuhkan. Untuk React/Vue, gunakan folder hasil build seperti dist atau build.
      3. Mulai Berbagi. SINZ menjalankan preview di 127.0.0.1, lalu meminta Quick Tunnel membuat URL publik.
      4. Bagikan URL. Buka URL dari HP atau perangkat lain yang terhubung ke internet.
      5. Hentikan Berbagi. Hentikan tunnel setelah selesai. URL Quick Tunnel tidak permanen.
      Panel admin hanya mendengarkan di komputer ini (127.0.0.1). Tunnel hanya membuka website statis yang dipilih, bukan panel admin. URL publik dapat diakses dari perangkat lain melalui internet, tanpa harus berada pada Wi-Fi yang sama.
      !

      Konfirmasi tindakan

      Pastikan tindakan ini memang ingin dilakukan.
