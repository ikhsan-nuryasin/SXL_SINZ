Dasar SQL

Perintah di editor dijalankan berurutan pada satu koneksi. Jika ada perintah gagal, perintah sebelumnya tidak otomatis dibatalkan. Gunakan titik koma untuk memisahkan perintah. Untuk operasi yang mengubah atau menghapus data, periksa klausa WHERE terlebih dahulu.

Tipe data umum

  • INT: bilangan bulat; BIGINT: bilangan bulat berukuran besar.
  • VARCHAR(255): teks dengan panjang maksimum; TEXT: teks panjang.
  • DECIMAL(10,2): angka desimal yang presisi untuk nilai uang.
  • DATE: tanggal; DATETIME: tanggal dan waktu.
  • BOOLEAN: nilai benar/salah (MariaDB menyimpannya sebagai angka kecil).

Contoh membuat tabel relasi

BUAT TABEL pelanggan (
  id INT,
  nama VARCHAR(100) BUKAN KOSONG,
  dibuat_pada DATETIME
);

Untuk primary key dan auto-increment, gunakan sintaks SQL standar di mode SQL standar, misalnya id INT AUTO_INCREMENT PRIMARY KEY.

Kamus perintah dan fungsi MariaDB
Perintah / istilahArti dan kegunaan
SELECT / PILIHMembaca kolom atau data dari tabel.
FROM / DARIMenentukan tabel sumber data.
WHERE / DIMANAMenyaring baris sesuai kondisi.
INSERT INTO / TAMBAHKAN KEMenambahkan baris baru ke tabel.
UPDATE / UBAHMengubah data; gunakan WHERE agar hanya baris yang dituju berubah.
DELETE FROM / HAPUS DARIMenghapus baris; tanpa WHERE semua baris di tabel dapat terhapus.
CREATE TABLE / BUAT TABELMembuat tabel dan menentukan kolom serta tipe data.
ALTER TABLE / UBAH TABELMengubah struktur tabel, misalnya menambah kolom.
DROP TABLE / HAPUS TABELMenghapus tabel beserta isinya.
JOIN / GABUNGKANMenggabungkan baris dari tabel terkait menggunakan kondisi ON.
ON / PADAMenentukan kondisi pencocokan pada JOIN.
ORDER BY / URUTKAN BERDASARKANMengurutkan hasil; ASC naik dan DESC turun.
GROUP BY / KELOMPOKKANMengelompokkan baris, umumnya bersama fungsi agregat.
LIMIT / BATASIMembatasi jumlah baris hasil yang dikembalikan.
COUNT()Menghitung jumlah baris atau nilai yang tidak NULL.
SUM()Menjumlahkan nilai numerik.
AVG()Menghitung rata-rata nilai numerik.
MIN() / MAX()Mengambil nilai terkecil atau terbesar.
NOW() / CURDATE()Mengambil waktu saat ini atau tanggal hari ini.
PRIMARY KEYPenanda unik untuk setiap baris tabel.
FOREIGN KEYRelasi yang menjaga keterkaitan antar tabel.
INDEXMembantu mempercepat pencarian, dengan biaya ruang penyimpanan dan penulisan.
COMMIT / SIMPANMenyimpan perubahan dalam transaksi.
ROLLBACK / BATALKANMembatalkan perubahan transaksi yang belum di-COMMIT.
